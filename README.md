## Work / Projects

### Credit Risk Analysis
This project is part of ** Data Exploration and Analysis**, focusing on understanding and modeling credit risk through data analysis techniques. The goal is to identify and interpret the factors influencing loan approvals using exploratory data analysis (EDA), statistical modeling, and hypothesis testing.

### Data Preparation and Integration 
This project showcases the essential steps involved in data preparation, with a focus on integrating data from diverse sources. The primary objective is to demonstrate proficiency in acquiring, cleaning, transforming, and visualizing data using industry-standard tools and techniques. By handling data from multiple formats—including flat files, web scraping, and APIs—the project emphasizes the importance of preparing high-quality, analysis-ready datasets. 

### Loan Default Risk Prediction Using Machine Learning - Data Selection , EDA. Classifcation modelling and Evaluation
This project addresses a common and critical problem in the financial industry: assessing the risk of loan default. Financial institutions need accurate and reliable models to determine whether a borrower is likely to repay a loan. The goal of this project is to build a predictive model that classifies loan applicants as high or low risk using financial and demographic data.

### Airline Passenger Satisfaction Classification
A classification project focused on predicting airline passenger satisfaction based on feedback related to services provided. The process includes data preparation, exploratory data analysis (EDA), and the application of various machine learning models, including an ensemble approach to improve prediction accuracy.

### Fine tune a LLM Model
This project demonstrates how to fine-tune an OpenAI language model, GPT,  using custom data. The goal is to create a model that provides precise and structured responses to domain-specific queries — in this case, about chicken recipes.

### Prevent fraudulent banking transactions
Build a real-time fraud detection system using machine learning techniques.

### Automated Scene Classification Using Deep Learning
Build  a deep learning model for automated scene classification using image data. Target to accurately categorize natural scenes—such as forests, mountains, and streets—into predefined categories using convolutional neural networks (CNNs) and transfer learning techniques.

### Custom Neural Network
This project demonstrates the development and evaluation of a **custom-built feedforward neural network** applied to the **IRIS** and **MNIST** datasets. The objective is to understand core neural network mechanics, including forward/backward propagation and how custom components compare with established libraries like Keras and PyTorch.

### Supervised Learning – Predict Patient condition and Customer adopting to digitalization of bank

### Recommendation system on Mobile brands
Focusing  on consumer behavior in growing smartphone market  a recommendation system to suggest smartphones based on user preferences and market data.

### Natural Language Processing -  Classify a Chat content Category
Develop a multi-label classifier that predicts attributes of text authors (e.g., demographics) using blog posts or social content. Leverage NLP techniques for author identification through their writing
